## Working pattern observed

> Audit note, 2026-10-30: no winner-by-winner source records are present yet. Treat the pattern below as a design hypothesis, not an established empirical result or official judging criterion. V3 does not assign points for unverified winner patterns.

A recurring structure in strong projects is:

`real user problem → NASA data → scientific/modeling layer → prediction/optimization/simulation → decision → action → visual proof/demo`

This is **not an official NASA judging formula**. It is a design heuristic that should be tested against official judging criteria and specific winner evidence.

## Questions to track

For each useful past project:

- Who was the user?
- What concrete decision/action did the product enable?
- How central was NASA data?
- Was AI actually necessary?
- Was there prediction, optimization or simulation?
- What was the live demo moment?
- How was scientific validity shown?
- What made the project memorable or impactful?

Detailed source-by-source notes should be added separately so the evidence can be audited.
