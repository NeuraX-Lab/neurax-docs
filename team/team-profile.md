## Team-selection principle

The best challenge for NeuraX should ideally use **most of the team naturally**, rather than forcing every discipline into the project.

A strong fit should provide meaningful work across:

1. **AI/data** — prediction, ranking, optimization, anomaly detection, or rigorous analytics.
2. **Environmental/GIS or scientific domain** — domain validity rather than decorative mapping.
3. **Software** — an end-to-end product, not only a notebook.
4. **Simulation / decision support** — allow a user to explore consequences, alternatives, or scenarios.
5. **Hardware** — optional but valuable when it adds real-world sensing/validation; it should not be forced into challenges where it is irrelevant.
6. **Evaluation** — the team should be able to demonstrate that the system works, not only that it looks good.
